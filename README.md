# data-analysis-study
# 📊 데이터 분석 학습 및 실습 기록

이 저장소는 **파이썬 기반 데이터 분석 및 수집 기술**을 학습하며 작성한 구글 코랩(Google Colab) 노트북들을 정리해둔 공간입니다.

---

## 🛠️ 사용 기술 및 환경
- **Language**: Python 3
- **Environment**: Google Colab
- **Libraries**: Pandas, NumPy, BeautifulSoup4, Requests, Matplotlib, Seaborn

---

## 📁 주요 학습 내용 (Directory)

| 번호 | 주제 | 주요 내용 및 실습 |
| :--- | :--- | :--- |
| **01-3** | **데이터 다루기** | Pandas 기초, DataFrame 구조 이해 및 기본 조작 |
| **02-1** | **API 사용하기** | Open API 호출, JSON 데이터 파싱 및 가공 |
| **02-2** | **웹스크래핑 사용하기** | BeautifulSoup을 활용한 HTML 파싱 및 웹 데이터 수집 |
| **03-1** | **불필요한 데이터 삭제하기** | 결측치(NaN) 처리, 중복값 제거 및 데이터 정제 |
| **03-2** | **잘못된 데이터 수정하기** | 이상치(Outlier) 처리, 데이터 타입 변환 및 전처리 |
| **04-1** | **통계로 요약하기** | 기술통계(평균, 중앙값, 분산 등) 산출 및 데이터 요약 |
| **04-2** | **분포 요약하기** | 히스토그램, 산점도, 도수분포표를 활용한 데이터 분포 분석 |

---

## 💡 주요 인사이트 및 요약
- **데이터 전처리**: 결측치 및 이상치 처리를 통해 분석 정확도를 높이는 전처리 프로세스 습득
- **데이터 수집**: REST API와 Web Scraping을 활용하여 비정형 웹 데이터를 데이터프레임으로 변환하는 방법 체득
- **탐색적 데이터 분석(EDA)**: 기초 통계량과 다양한 가시화 기법을 통해 데이터의 특성을 빠르게 파악하는 능력 배양
